Nächste Entwicklungsschritte

Die Roadmap.

Prioritäten statt einer endlosen Wunschliste. Neue Module sollen nicht auf Kosten bestehender Trainingsdaten gehen.

01

Stabile Basis & Datenmigration

Builds überprüfen, Regressionen vermeiden, Backup und Wiederherstellung absichern. Vor allem Übungen, Bilder und Animationen sauber prüfen.

02

Ernährung übersichtlich machen

Makroringe verständlich gestalten, tägliche Ziele und Ergänzungen besser darstellen, Lebensmittelerfassung konsolidieren.

03

Trainingsintelligenz

Automatische Progression für A/B/C, Trainingsanalyse, sinnvolle Empfehlungen und verlässlicher Pausentimer.

04

Trends & Import

Körperentwicklung, Gewicht und Kraftverlauf sowie spätere Ernährungsplan-Imports aus PDF oder Foto mit Rezeptvorschau.

Entwicklung / Vorabversion

Das GitHub-Frontend trägt derzeit die Paketversion 0.3.7-rc.8. Eine erfolgreiche Installation und die vollständige Funktion aller Module sind damit nicht bewiesen. Die Android-Version wird über GitHub Actions gebaut.

Wichtig zu Übungsbildern und Animationen: Die ursprünglichen openGym-Medien können gesonderten Lizenzbedingungen unterliegen. Diese Website bindet keine solchen Inhalte ein. Die Verfügbarkeit in openForm muss rechtlich und technisch geklärt werden. Ebenso ist das Repository derzeit privat: GitHub-Links sind nur mit entsprechender Berechtigung zugänglich.

Projekt auf GitHub ansehen.

Code, Versionsverlauf und Android-Builds befinden sich im Repository. Ein GitHub-Actions-Artefakt ist nicht automatisch ein geprüftes Release.

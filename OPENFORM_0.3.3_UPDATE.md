# openForm 0.3.3 – Ernährung, Coach und Wasserziel

Dieser Patch baut auf openForm 0.3.2 auf. Er enthält die neue ausklappbare Nährstoff-/Supplement-Ansicht im Essen-Tab, entfernt das doppelte Profilmenü, erlaubt 1900 ml ohne Browser-Warnung und bietet im Coach lokale Ernährungsauswertungen auch ohne API-Guthaben. Trainingspläne benötigen weiterhin den bestehenden KI-Anbieter; es wird **keine** automatische externe Übertragung lokaler Mahlzeiten durchgeführt.

Für das vorhandene GitHub-Repo: ZIP-Inhalt ins Repo-Stammverzeichnis entpacken, `git add -A && git commit -m "openForm 0.3.3" && git push origin main` ausführen. GitHub Actions baut das Artifact `openForm-0.3.3-debug`. Zur Installation ist die bisherige Signatur nötig. Keystore niemals ins Git-Repo hochladen.

Android-Build muss noch auf GitHub erfolgreich durchlaufen. Die Quellen enthalten keine APK.
